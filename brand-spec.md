# Brand specification — Sol Energía

## Proyecto

Landing one-page para captación de consultas sobre medición de puesta a tierra y continuidad de masas conforme SRT 900/2015.

## Identidad visual

- **Marca:** Sol Energía.
- **Sitio oficial consultado:** https://www.solenergia.com.ar/
- **Paleta funcional:** verde profundo para autoridad y seguridad; verde medio para acción; lima y amarillo para acentos de atención; blanco y gris verdoso para lectura.
- **Tipografía:** Arial/Helvetica del sistema para máxima compatibilidad y rendimiento.
- **Radio:** 9 px para botones y 16–20 px para tarjetas y bloques destacados.
- **Movimiento:** desplazamiento suave nativo y transiciones discretas en botones y WhatsApp flotante.

## Recursos usados

- `img/logo-Sol-energia-2017-web-2.png`: logotipo oficial para encabezado y pie.
- `img/Puesta-a-Tierra-ART.jpg`: imagen principal de una medición de puesta a tierra.
- `img/medicion-2026.webp`: imagen secundaria de instrumental durante una medición eléctrica.

Se dejaron fuera las imágenes restantes para reducir peso visual y mantener el foco de conversión.
